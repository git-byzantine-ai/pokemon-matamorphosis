# Windows portable alpha 0.1.0-alpha.1

Download **Pokemon-Metamorphosis-0.1.0-alpha.1-Windows-x64.zip** below, extract the entire folder, and open **Metamorphosis.exe**. The GitHub source-code archives are for developers.

1. Choose your original English FireRed v1.0 ROM and click **Set up / Repair**.
2. Select your graphics device and click **Test AI**.
3. Click **Play**, then load the bridge through mGBA's **Tools > Scripting > File > Load script** using the launcher's **Copy bridge path** button. Load it once per emulator session and keep the launcher open.

No Python, Git, Codex, API key or administrator installation is required. Setup downloads about 2.2 GB; allow at least 4 GB of free space. A Vulkan GPU is recommended. The original ROM is supplied by the player and is never modified; the package contains a patch. AI generation runs locally.

This includes manual essence application/refunds, triple EV yields, the 100-EV artwork threshold, canonical front conditioning, and front-guided back generation. Saves, essence history and artwork are stored together separately from the app. A player guide, backup button and third-party notices are included.

Validated on Windows 11 with an NVIDIA RTX 4070 Laptop GPU: standalone setup with development tools removed from PATH, actual emulator/runtime downloads, verified model import, real AI generation, emulator boot and Lua connection, update preservation and save/history backup. All 41 automated tests pass. This is an unsigned experimental prerelease; a clean second PC, other GPUs and a full campaign have not been validated. Existing development-checkout saves are not automatically imported.

The adjacent `.sha256` file contains the ZIP checksum. Read `PLAYER_GUIDE.txt` before transferring saves or updating.
